# Planes de Aurora

Los planes se archivan aquí cuando se ejecutan. No son documentación del sistema:
son el registro de lo que se decidió y por qué. La verdad viva está en `README.md`,
`LLM.md`, `COMPOSICION.md` y `AGENTS.md`.

| Plan | Qué cubrió | Estado |
|---|---|---|
| `PLAN-AURORA-v7.md` | Coherencia, tipografía, color y composición (v7.2.2 → v8.4.2) | Ejecutado |
| `PLAN-AURORA-9.md` | Responsive multifunción (container queries) y API de consulta LLM (v9.x) | En ejecución |

Regla: un plan que ya se ejecutó no se queda en la raíz. Se archiva aquí para que la
raíz del repo enseñe el sistema, no su historia.
